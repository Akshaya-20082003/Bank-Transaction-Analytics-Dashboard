# 📊 Bank Transaction Analytics Dashboard

## 📌 Project Overview
This project analyzes **bank transactions** using SQL & Excel to generate insights on customer spending patterns.  
It includes **SQL queries, CSV datasets, Excel-based visualizations, and an interactive dashboard**.  
The final output helps in identifying **spending trends by gender, age group, payment mode, merchant, and category**.

---

## ✨ Features
- SQL scripts for **database creation, data insertion, and queries** (Basic + Advanced).
- CSV datasets for analysis.
- Multiple **Excel charts** (Pie, Bar, Column, Line, Doughnut).
- Final **Bank Transaction Dashboard** in Excel & PDF.
- Project Report (optional) summarizing problem statement, methodology, and insights.
- Screenshots for step-by-step demonstration.

## 📑 Project Report (Text Version)
**Title:** Bank Transaction Analysis Dashboard  
**Author:** Prachi Singh  
**Date:** August 2025  


### 🔹 Problem Statement
Banks need better insights into customer spending patterns to improve decision-making and detect anomalies.  


### 🔹 Data Source
Dummy bank transaction dataset (CSV + SQL + Excel).  


### 🔹 Methodology
- Data creation and insertion using SQL.  
- Writing queries (15 Basic + 15 Advanced) for analysis.  
- Exporting datasets to CSV.  
- Visualizing spending patterns using Excel charts.  
- Creating a consolidated dashboard.  


### 🔹 Charts Used
- Gender-wise spending  
- Payment mode percentage share  
- Category-wise spending  
- Age group spending  
- Merchant-wise spend  
- City-wise transaction count with trendline  
- Day-wise total spend  
- Spend category distribution  


### 🔹 Insights
- Most spending comes from the **26–35 age group**.  
- **Amazon** was identified as the top merchant.  
- **NetBanking** had the highest usage compared to POS/UPI.  
- Travel and Shopping contributed to major spend categories.  


## ✅ Conclusion
This project demonstrates how **SQL + Excel** can be combined to build powerful **Bank Transaction Analytics Dashboards**.  
It can help in **business decision-making, identifying spending behavior, and merchant performance analysis**.
